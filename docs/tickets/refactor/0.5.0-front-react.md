# 0.5.0 — Les pages en React + TypeScript

## Ce que ça fait

Rien de neuf pour l'utilisateur. Les trois pages (icône, bulle, panneau) sont
réécrites en React + TypeScript et découpées en petits modules. Elles doivent
se comporter exactement comme en 0.4.0 : mêmes écrans, mêmes messages vers le
principal. Références : `SPEC.md`, et la note Obsidian « Whisper 0.4.0 - État
des lieux et invariants ».

Le principal (`src/*.js`) et les ponts (`*preload.js`) ne changent pas, sauf
le chemin des pages : `out/renderer/`, construit par Vite. Ils passeront en
TypeScript dans la PR suivante.

## Ce que ça ne doit pas faire

- Ouvrir, retirer ou détourner un canal entre une page et le principal :
  chaque page n'a que les siens, et le principal vérifie l'expéditeur
  (I-3, I-20). → invariant (`tests/invariants/bridges.test.ts`)
- Terminer un enregistrement sans prévenir le principal. Le son et le micro
  Discord resteraient coupés (I-11). → invariant
  (`icon/tests/invariants/recording.test.ts`)
- Répondre à une autre demande d'autorisation que celle affichée, ou à un clic
  arrivé dans le délai qui suit une nouvelle demande (I-15, I-16). →
  invariant (`panel/tests/invariants/permission.test.ts`)
- Rendre cliquable autre chose qu'une adresse `http(s)`, ou naviguer au clic
  (I-21). → invariant (`shared/tests/invariants/links.test.ts`)
- Envoyer à whisper un enregistrement trop court ou silencieux (I-10). →
  variant
- Mélanger les brouillons de deux conversations, ou mettre la dictée dans le
  brouillon d'un autre agent (S-22). → variant
- Charger une page autrement que par `file://` : le micro n'est accordé qu'à
  `file://` (I-9). Exécuter un script en ligne : la CSP des pages est
  inchangée. → structure (`base: './'` dans Vite)
- Différer en apparence ou en messages de la 0.4.0. → comparaison
  (`tests/front-diff`, à lancer avant la fusion)

## Où ça casse

- Une page cachée n'exécute pas `requestAnimationFrame`, et ses minuteries
  sont ralenties. La bulle mesure donc sa hauteur dans le même tour que
  l'affichage du message (`flushSync`).
- Pendant un tour, le fil est renvoyé en entier au plus toutes les 800 ms.
  Les messages ont une clé stable, rien n'est remonté ; un `<details>` ouvert
  le reste.
- Le panneau réduit prend la hauteur de son contenu : chaque rendu la remesure
  (mêmes éléments, même calcul qu'en 0.4.0).

## Ce que ça touche

`src/main.js` (chemins des pages), `package.json` (scripts, dépendances de
développement, fichiers du paquet), CI (typage, tests, construction des
pages), `README.md` (depuis les sources), `SPEC.md` (§ 1), `LINUX_SETUP.md`
(lanceur `whisper-dev`).

## Forme

```
src/renderer/
  bridge.d.ts        types des ponts (window.api, window.bubble, window.conv) et des
                     données échangées · aucun code · utilisé par les trois pages
  shared/
    links.ts         splitLinks(texte) → segments ; seules les adresses http(s)
                     deviennent des liens · pur
    Linkified.tsx    rend les segments ; un clic appelle onOpen(url), ne navigue pas
  icon/              la fenêtre de l'icône
    audio.ts         toPcm, rms, isSilent · pur
    recorder.ts      openMic (micro retrouvé par son nom), listInputs, record
                     · ne connaît pas React ni le pont
    dictation.ts     createDictation(deps) : un appui long = une dictée (coupures,
                     micro, bips, transcription, message de l'infobulle)
                     · ne connaît pas React ; pont et micro injectés
    speech.ts        createSpeechPlayer(deps) : lecture par morceaux, état du bouton
                     · ne connaît pas React ; pont et AudioContext injectés
    gesture.ts       useGesture : glisser ou maintenir
    beep.ts          bips
    AgentButtons.tsx robots : affichage seul (props), ne connaît pas le pont
    PlayButton.tsx   bouton de lecture : affichage seul
    IconApp.tsx      colle : seul fichier de l'icône qui connaît window.api
  bubble/
    BubbleApp.tsx    message, volume ; seul fichier qui connaît window.bubble
  panel/             le panneau des conversations
    format.ts        heures, durées, jetons, jauge, intitulé, début du réduit · pur
    permission.ts    createPermissionGuard : la demande affichée et le délai
                     anti-clic · pur
    drafts.ts        un brouillon par conversation, dictée ajoutée · pur
    slash.ts         commandes « / » : requête, filtre, choix · pur
    pieces.ts        pièces jointes : pictogramme, libellé, brouillon envoyé · pur
    height.ts        hauteur du réduit, mesurée sur ses éléments · DOM seul
    Header.tsx, Banners.tsx, Thread.tsx, PermissionCard.tsx, Composer.tsx,
    HistoryList.tsx, ContextDetail.tsx
                     affichage : props et rappels, aucun ne connaît window.conv
    PanelApp.tsx     colle : seul fichier du panneau qui connaît window.conv
tests/invariants/bridges.test.ts   les ponts et les contrôles d'expéditeur du principal
tests/front-diff/                  0.4.0 contre la version courante, mêmes scénarios
```
