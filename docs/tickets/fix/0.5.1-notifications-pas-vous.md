# 0.5.1 — Les notifications de Claude Code ne s'affichent plus comme « Vous »

## Ce que ça fait

- Les messages que Claude Code s'envoie à lui-même (fin d'une tâche de fond :
  `<task-notification>…`) ne s'affichent plus dans le fil comme un message
  de l'utilisateur. Ils sont écartés, comme les messages méta : la réponse de
  l'agent qui suit dit ce qui compte.
- Dans la transcription, ce sont des entrées `type: 'user'` marquées
  `origin: { kind: 'task-notification' }` (`promptSource: 'system'`) ; les
  vôtres n'ont pas d'`origin` (anciennes) ou `origin.kind === 'human'`.
  `parseThread` ne regarde pas `origin`.

## Ce que ça ne doit pas faire

- Afficher comme « Vous » un message dont l'origine n'est pas humaine. →
  variant (rouge avant le fix), sur une entrée relevée telle quelle
- Écarter un message tapé ou dicté (sans `origin`, ou `human`). → variant

## Ce que ça touche

- `core/agents/sessions.ts` : `parseThread` écarte les entrées dont
  `origin.kind` existe et n'est pas `human` (toute origine machine future
  comprise, pas seulement `task-notification`).
- SPEC F-66 : « les messages internes de Claude Code (notifications de
  tâches) ne sont pas affichés ».

## Pistes pour plus tard

- Les montrer en message « système » (une ligne : tâche terminée, arrêtée)
  si leur absence gêne.
