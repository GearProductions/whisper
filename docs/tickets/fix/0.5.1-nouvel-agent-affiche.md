# 0.5.1 — Nouvel agent : le panneau ouvert passe à sa conversation

## Ce que ça fait

- Panneau ouvert sur un agent, « + » → *Nouvel agent dans un dossier
  favori* (ou *Choisir un autre dossier…*) : le nouvel agent est sélectionné
  **et** le panneau affiche sa conversation. Aujourd'hui seule la sélection
  change (`newAgent` écrit `agentSelected` sans passer par
  `openConversation`) : le robot sélectionné et le robot affiché divergent,
  et la dictée suivante part vers un agent que le panneau ne montre pas.
- Panneau fermé : inchangé, le nouvel agent est sélectionné, rien ne s'ouvre.

## Ce que ça ne doit pas faire

- Laisser le robot sélectionné différent du robot affiché, panneau ouvert. →
  vu en review (S-35)
- Ouvrir le panneau quand il était fermé. → vu en review

## Ce que ça touche

- `app/controllers/agents.ts` : `newAgent` fait comme `clickAgent` —
  panneau montré : `openConversation(agent.id)` ; sinon `selectAgent` +
  `pushAgents`. Seul autre écrivain de `agentSelected` hors
  `openConversation` : *Retirer* (désélection, le panneau se ferme déjà).
- SPEC F-52, S-35 ; README.
