# 0.5.1 — Agrandir le panneau garde le fil en bas

## Ce que ça fait

- ⤢ (réduit → agrandi) : le fil s'ouvre en bas, sur le dernier échange,
  comme en réduit. Aujourd'hui il s'ouvre en haut de la conversation (le
  changement de taille n'est pas une raison de descendre : même conversation,
  même nombre de messages, `toEnd` reste faux et le fil garde la position du
  réduit, 0).

## Ce que ça ne doit pas faire

- Arracher la lecture d'un message plus ancien quand un message arrive en
  agrandi (F-66). → variant
- Rester en haut après ⤢. → variant (rouge avant le fix)

## Forme

```
core/conversation/thread.ts   followsEnd(before, next, { atEnd, working }) → boolean :
                              descendre le fil après ce rendu ; pur, ne connaît pas le DOM.
                              Reprend la règle de panel-app (autre conversation, réduit,
                              demande d'autorisation, message arrivé en bas) + changement
                              de taille. Utilisé par : app/panel (panel-app).
```

## Ce que ça touche

- `app/panel/panel-app.tsx` : `onThread` appelle `followsEnd` au lieu du
  calcul en ligne.
- SPEC F-66 : « ⤢ ouvre le fil en bas ». S-xx : ⤢ sur une longue
  conversation → dernier échange visible.
