# 0.13.0 — Recharger l'interface en mode dev

## Ce que ça fait

En mode dev (`whisper-dev`, l'appli lancée depuis les sources), on itère sur
l'interface sans arrêter les agents :

- `whisper-dev` reconstruit les pages en continu (`vite build --watch`, dans
  la box) tant que l'appli tourne : enregistrer un fichier de `src/renderer`
  suffit à les reconstruire.
- Un bouton **Recharger l'interface**, dans l'en-tête de VibeCoder, à droite,
  à côté de FR / EN, recharge les fenêtres de l'appli (icône, bulle,
  panneau) avec les pages reconstruites. Le principal ne redémarre pas : les
  agents et leurs tours continuent.
- Le bouton n'existe qu'en mode dev ; dans la version publiée, rien ne change.
- Un changement du principal (`src/main`) demande toujours `whisper-dev
  restart`.

## Ce que ça ne doit pas faire

- Apparaître ou agir dans la version publiée (l'appli empaquetée). → variant
  suffit (le principal refuse aussi, `app.isPackaged`)
- Arrêter un agent, interrompre un tour, redémarrer le principal. → vu en
  review
- Ouvrir un canal nouveau entre les pages et le principal (`src/preload/`,
  `channels.ts` inchangés). → vu en review

## Ce que ça touche

- `src/shared/bridge/types.ts` : `VibeView.dev`, `VibePatch.reloadUi`.
- `src/main/app/controllers/vibecoder.ts` : le relevé dit s'il est en dev ;
  `setVibe({ reloadUi })` recharge les fenêtres, en dev seulement.
- `src/renderer/app/panel/vibecoder/vibe-coder.tsx`, `core/vibecoder` (i18n)
  : le bouton.
- `~/dev/Gear/tools/whisper.sh` (hors du dépôt) : la construction continue
  des pages.
- `README.md` (le mode dev).

## Forme

```
shared/bridge/types.ts      VibeView.dev?: boolean (l'appli tourne depuis les
                            sources : !app.isPackaged) ; VibePatch.reloadUi?:
                            true (recharger les fenêtres)
main/app/controllers/vibecoder.ts  survey : dev au relevé ; setVibe :
                            reloadUi → chaque fenêtre rechargée
                            (webContents.reloadIgnoringCache), seulement si
                            !app.isPackaged ; rien d'autre ne suit
renderer/app/panel/vibecoder/vibe-coder.tsx  Recharger l'interface, à côté de
                            FR / EN, si view.dev : act.set({ reloadUi: true })
renderer/core/vibecoder/i18n.ts  ses libellés (fr, en)
```
