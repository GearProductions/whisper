# 0.15.0 — Montrer un artefact dans le dossier

Branche `feat/0.15.0-artefact-dossier`, créée depuis `master`. PR express (une petite amélioration, demandée par l'utilisateur).

## Ce que ça fait

En tête d'un artefact, à côté d'*Ouvrir dans l'éditeur* et de *Copier dans le projet*, une icône de dossier, *Montrer dans le dossier* : le gestionnaire de fichiers s'ouvre sur le fichier de l'artefact, sélectionné, pour le récupérer ou l'envoyer à quelqu'un.

## Ce que ça ne doit pas faire

- Lancer le fichier (un script se lancerait) : il est seulement montré → variant suffit
- Recevoir un chemin de la page : l'écran passe l'id de l'artefact (`dir:<id>`, par le canal d'*Ouvrir*, `conv:vibeOpen`), le principal retrouve son fichier dans les artefacts du projet (I-3) → variant suffit

## Ce que ça touche

`src/main/app/controllers/vibecoder.ts` (`openVibeItem`), `src/renderer/app/panel/vibecoder/artifacts-view.tsx`, `icons.tsx` (l'icône `folder`), `src/renderer/core/vibecoder/i18n.ts` ; aucun canal nouveau. SPEC, README.
